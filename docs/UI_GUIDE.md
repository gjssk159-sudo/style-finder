# UI 가이드

> 최종 확인: YYYY-MM-DD · 정본: 토큰 값은 `<토큰 파일 경로, 예: src/styles/tokens.css>`, 규약은 이 문서.
> **값이 충돌하면 CSS(토큰 파일)가 정본**이다. 이 문서의 표는 그것을 가리키고, 고칠 때 같은 커밋에서 함께 고친다.
> 빈칸(`<…>`)은 프로젝트에 맞게 채우고, 해당 없는 절은 "해당 없음"으로 남긴다.

## 1. 모드·범위

| 산출물 | 모드 | 이유 |
|---|---|---|
| `<앱 화면>` | consumer | `<누가 어떤 상황에서 쓰나>` |
| `<랜딩>` | marketing | |
| `<관리자>` | tool | |

- 화면 목록: `<S1 홈, S2 …>`
- 채널 예산: 살릴 것 `<예: 색·서체>` / 절제할 것 `<예: 모션·그림자·반경>`

## 2. 정체성 근거

- 브랜드 기준: `<로고·브랜드 색·서체 출처, 변형 금지 규칙>`
- 한 문장 인상: `<예: 차분하고 믿을 만한>` — 모든 결정은 이 문장으로 판정한다.

## 5. 한글 조판

- 본문: `word-break: keep-all` + `overflow-wrap: anywhere` (짝으로)
- 행간: 본문 `<1.6>`, 제목 `<1.25>` · 자간: 32px 이상 제목 `<-0.02em>`, 본문 0
- 숫자·금액·표: `font-variant-numeric: tabular-nums`

## 6. 컴포넌트·상태

- 버튼: 주(1개/화면)·보조·위험. 라벨은 행동 동사. 파괴 행동은 확인 대화상자.
- 폼: 라벨 항상 표시, 오류는 필드 옆 + `aria-describedby`, 입력값 보존.
- 상태 5종(모든 화면): 비어 있음 · 로딩(구조 스켈레톤) · 오류(무엇이·왜·다음 행동) · 부분(권한·오프라인) · 가득(긴 이름·많은 항목)

## 7. 접근성

- 키보드만으로 핵심 동작 가능, 포커스 표시는 `:focus-visible`로 항상 보이게
- 아이콘 전용 버튼에 접근 가능한 이름, 색에만 의존하는 정보 금지
- 터치 대상: 모바일 44px 권장, 최소 24px · 확대 금지 메타 금지

## 8. 모션

| 밴드 | 토큰 | 값 | 쓰는 곳 |
|---|---|---|---|
| micro | `--dur-micro` | `<120ms>` | 호버·누름 피드백 |
| move | `--dur-move` | `<220ms>` | 펼침·이동 |
| enter | `--dur-enter` | `<360ms>` | 화면·모달 등장 |

- `transform`·`opacity`만, `transition: all` 금지, 상시 움직임은 화면당 1~2개
- `prefers-reduced-motion: reduce`에서 밴드 토큰을 0ms로. 모션을 꺼도 내용이 전달돼야 한다.

## 9. 반응형

- 기준 폭: 375 / 768 / 1440 (시각 회귀 뷰포트와 같게)
- `100vh` 대신 `dvh`, 고정 요소는 `safe-area-inset` 고려, 가로 스크롤 0
