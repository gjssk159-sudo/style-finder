# buildlog — 작업 일지

- 한 달에 한 파일: `YYYY-MM.md`(예: `2026-10.md`). 첫 줄은 `# buildlog YYYY-MM`.
- `/wrap`할 때마다 **제목 바로 아래**에 블록을 하나 넣는다(최신이 위).
- 지난 블록과 지난 달 파일은 고치지 않는다(오타 제외). 지금 상태는 여기가 아니라 `docs/STATUS.md`에.

## 블록 형식 (5단)

```markdown
## YYYY-MM-DD(요일) — 한 줄 제목 (#n)
### 한 일
### 검증
### 대기
### 다음 첫 작업
### 주의
```

| 칸 | 쓰는 것 |
|---|---|
| 한 일 | 바꾼 것과 이유. 파일 경로는 실제로 있는 것만 |
| 검증 | 실행한 명령 → exit 코드·건수. 안 돌린 것은 `미검증: <명령>` |
| 대기 | 사람·CI·리뷰를 기다리는 것 + 확인 명령(예: `gh pr checks 12`). 없으면 "없음" |
| 다음 첫 작업 | 다음 세션이 제일 먼저 할 일 하나 + 명령 |
| 주의 | 다음 사람이 밟을 함정, 바꾸면 안 되는 것 |
