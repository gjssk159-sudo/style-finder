# T-04 리뉴얼 — 틀 A "브랜드 소식형" 적용 (#4)

> 결정: D-4(브랜드 따라가기 중심), D-5(틀 A, 아래 메뉴 홈·브랜드·＋등록·AI·마이, 검색은 홈 맨 위).
> 시안: `docs/design/drafts/2026-11-06-structure/index.html` A 줄. 근거: `design-kit/research/structure/STRUCTURE.md`.
> **기능은 그대로**(design-kit DD-2): 검색·필터·폴더 3개·공유·브랜드 등록·질문하기·AI·로그인·마이. 배치와 화면 나눔만 바꾼다.
> 분위기: D-6 룩북형(시안 `docs/design/drafts/2026-11-06-visual/`). 각 단계에서 바꾸는 화면에 이 모양을 같이 입힌다. 색·글꼴 값은 `web/index.html` `:root` 토큰에 먼저 정의하고 그것만 쓴다.

## 2. 작업 (한 단계 = 한 커밋, 단계마다 사용자에게 보고)
0. **안전망** — 가짜 데이터 화면 시험 `scripts/ui-smoke.mjs`: Supabase 요청을 가로채 화면을 띄우고, 지금 기능이 살아 있는지 확인(검색어 → 상품 요청, 폴더 열기, 브랜드 등록 창, AI 화면, 질문하기, 마이). 바꾸기 **전에** 통과시켜 기준선으로 삼는다.
1. **아래 메뉴** — 홈·브랜드·＋등록·AI·마이. 지금 "내 폴더" 탭이 하던 일은 홈의 브랜드 줄 + 브랜드 화면으로 옮긴다(폴더 관리 창은 그대로 열 수 있게).
2. **홈** — 맨 위 검색 → 담은 브랜드 동그라미 줄(누르면 그 브랜드) → 브랜드마다 "이름 · 전체 ›" + 최근 상품 가로 줄. 검색어를 넣으면 지금처럼 전체 결과 목록으로.
3. **브랜드 화면** — 지금 상품 목록을 그 브랜드로 거른 화면 + 머리(이름·담기/빼기·쇼핑몰 바로가기). 분류 칩·정렬·필터 그대로.
4. **브랜드 목록** — 지금 폴더 창의 브랜드 목록·검색을 한 화면으로: 최근 등록된 브랜드 → 가나다순(담기) → "목록에 없는 브랜드 등록".
5. **마무리** — 빈 화면·로그인 전·공유 폴더 보기 화면 점검, 데스크톱 폭 점검.

## 3. 완료 조건 (명령)
- `node scripts/ui-smoke.mjs` → 0단계 기준선의 기능 확인 항목 모두 통과(바꾼 뒤에도 같은 항목)
- `npm run check` 통과
- `node "<design-kit>/plugin/scripts/audit.mjs" .` → 지킬 것 0건
- 390px·1280px 화면 사진 전후 비교, 사용자 확인
- push(배포)는 사용자 확인 후

## 4. 검증
- 단계마다 ui-smoke + 화면 사진. 실제 데이터로는 사용자가 `localhost:5173` 에서 로그인해 확인.
- 데이터베이스 쓰기(담기·빼기·등록·질문)는 가짜 데이터 시험에서만 누른다. 실제 계정으로 누르지 않는다.

## 5. 금지
- 기능 추가·삭제(찜, 할인율, 추천 같은 새 기능 X), Supabase 스키마·RLS·Edge Function 변경(`supabase/**`), `web/config.js` 수정
- 시안에 없는 새 모양 임의 추가, 운영 데이터 쓰기, 사용자 확인 전 push
