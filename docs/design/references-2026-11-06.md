# 사용자 레퍼런스 분석 — 2026-11-06

> 원본 사진 3장: `design-kit/references/마이셀렉트샵/`(이 컴퓨터에만, 저장소에 안 올림). 출처 표시: 샤오홍슈(rednote) 공유 이미지, 패션 룩북·쇼핑몰 시안.
> 베끼지 않는다. 아래 **결정**만 가져온다.

| # | 보이는 것 | 가져올 결정 |
|---|---|---|
| R1 | 모델 전신 사진이 크고, 바탕은 흰색·옅은 종이색 | 사진을 가장 크게. 바탕은 옅은 종이색, 장식 면(카드 바탕·그림자) 없음 |
| R2 | 아주 큰 제목(굵은 세리프 / 가늘고 넓은 대문자) + 아주 작은 설명(LOOK 01, 2025 FW, 구석 라벨) | 글자 크기 차이를 극단적으로: 브랜드 이름은 크게, 나머지는 작게. 작은 번호·라벨로 "목록" 느낌 |
| R3 | 비대칭 배치, 사진과 글자가 겹침, 넉넉한 여백 | 섹션마다 똑같은 격자만 반복하지 않고, 한 곳은 크게·비대칭으로 |
| R4 | 화면은 흑백, 빨강은 옷 사진에서만 | 화면 색은 흑·백·회색. 포인트 색을 따로 만들지 않는다 |
| R5 | 상품은 흰 칸에 상품만, 작은 이름·가격, 테두리·그림자·모서리 없음 | 상품 칸은 사진 + 작은 글 두 줄 |
| R6 | "큰 제목 + See more →" 다음에 상품 한 줄 | 틀 A(D-5)의 "브랜드 이름 · 전체 ›" + 새 상품 가로 줄과 같은 구조 |

주의: 상품 사진은 각 브랜드 쇼핑몰에서 오므로 바탕·구도가 제각각이다. 레퍼런스처럼 "흰 바탕 누끼"를 보장할 수 없다 → 사진 칸 바탕을 옅은 회색으로 통일해서 제각각인 사진을 묶는다.
