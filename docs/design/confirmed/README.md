# 컨펌본 보관소

승인된 시안을 **날짜 폴더 단위로 박제**하는 곳이다. (harness-kit design)

- 폴더 이름: `YYYY-MM-DD[-짧은설명]/` — 예: `2026-11-03-landing-v1/`
- 넣을 것: 승인된 아트보드(HTML/이미지), 데스크톱·모바일(375)·모션 정지 캡처, 컨펌 질문과 답(`CONFIRM.md` 한 장)
- **박제한 폴더는 고치지 않는다.** 바뀌면 새 날짜 폴더를 만든다. 결정은 `DECISIONS.md`에 D-번호로 한 줄.
- 구현과 다를 때 무엇이 맞는지는 `docs/UI_GUIDE.md` §11을 따른다(값 충돌 시 토큰 CSS가 정본, 정정 이력은 남긴다).
- 큰 바이너리(영상·원본 디자인 파일)는 저장소 대신 공유 드라이브에 두고 여기에는 링크만.
